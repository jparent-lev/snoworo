# Visuels de la page Facebook

Visuels de la première série de publications (novembre 2026), textes dans le
document « Page Facebook Snowro ».

| Fichier | Usage | Format |
|---|---|---|
| `profil.png` | Photo de profil | 720 × 720 |
| `couverture.png` | Photo de couverture (contenu dans la zone visible sur téléphone) | 1640 × 624 |
| `01-lancement.png` à `10-partout.png` | Publications 1 à 10 (`02a` à `02c` : carrousel de la publication 2) | 1080 × 1080 |

`generer-visuels.cjs` les produit avec Playwright à partir de gabarits HTML aux
couleurs et polices du site ; les éléments du site (étapes, calculateur de
frais, carte des villes) sont des captures de snowro.com.
